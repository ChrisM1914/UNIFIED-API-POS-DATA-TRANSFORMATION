#Reflections

This assignment had me build a Flask ETL pipeline for an application. The ETL collects item and order information from the source API and shows it in one place. The API data is shared in two different formats, so the data had to be translated into a common format. The data was collected, formatted, saved in a database, and then was able to be displayed in a browser.

I updated the ETL code and added an identifier that would show in every unified column sku_id. I knew that the old database would not update, so I had to delete it and start fresh. My code has evolved enabling me to taking a raw integer from two systems and making an updated sku_id that is shared by both.

I understand APIs and ETLs better than I did before. I want to learn more about them and how I may be able to incorporate them into different everyday uses, while also making the output more aesthetically pleasing and reader friendly.
